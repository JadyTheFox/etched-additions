# Etched Additions

Companion mod for [Etched](https://modrinth.com/mod/etched) on Minecraft 1.21.1 (NeoForge).

- Every jukebox loops (vanilla discs, Etched discs, minecart jukeboxes)
- Per-jukebox volume, hearing range, pause and loop (sneak + right-click: empty hand = pause, stick = settings)
- Album jukebox: Pause / Play, Repeat One / All, Settings buttons
- Boombox track skipping (N = next, B = previous)
- Works with Sound Physics Perfected: songs keep their echo and still loop / advance

## Building
Requires Java 21. Put `etched-5.1.0.jar` in `libs/`, then run:

    ./gradlew build

The jar ends up in `build/libs/`.
